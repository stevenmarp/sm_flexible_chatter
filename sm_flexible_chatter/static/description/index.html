Flexible Chatter

Enhanced Chatter Experience - Flexible Position, Resizable Width, Message Pinning & Fullscreen Mode

Watch It In Action

See how Flexible Chatter transforms your Odoo chatter experience.

Key Features

Flexible Position

Choose between Auto, Sided, or Bottom chatter position. Each user can set their own preferred layout in Preferences.

Resizable Width

Drag the left edge of the chatter to resize it. Width is saved automatically per user in browser localStorage (300px–800px).

Message Pinning

Pin important messages to keep them at the top. Blue highlight + PINNED badge. Persists across sessions.

Fullscreen Mode

Toggle chatter visibility with one click. Hide chatter for maximum form space, show it again when needed.

Real-time Updates

New tracking messages appear automatically without page reload. MutationObserver detects changes in real-time.

Persistent Settings

All preferences — width, pins, fullscreen state — are saved in localStorage and persist across browser sessions.

How It Works

Open Preferences

Go to Settings > Users > Preferences tab to find the Chatter Position setting.

Choose Position

Select Auto (default), Sided (right panel), or Bottom for your chatter layout.

Pin Messages

Hover any message > click pin icon > message moves to top with blue highlight.

Enjoy!

All settings auto-saved. Resize, pin, toggle — everything just works across all form views.

Why This Module?

Per-User Settings

Each user can independently choose their preferred chatter position. No admin configuration needed — each person picks what works best for them.

Zero Performance Impact

Lightweight JavaScript using OWL patches and DOM manipulation. No heavy backend processing, no extra API calls, no slowdown.

Community & Enterprise

Works on both Odoo Community and Enterprise editions. Only depends on web and mail modules — available in every Odoo installation.

Works on All Forms

Applies to every form view with chatter — Sales Orders, Invoices, Contacts, Projects, and any custom model with mail.thread.
